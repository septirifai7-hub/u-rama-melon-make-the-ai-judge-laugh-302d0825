## The joke

> Our office printer only jams on deadline day, which is why my review now lists 'printer whisperer' under core skills.

Printers have a sense of occasion — they only jam when it matters. The punchline promotes a daily annoyance into a professional qualification.

## Usage

Run `main.py`; it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validating the 1–200 character, single-line gate first.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
